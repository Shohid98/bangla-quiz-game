বাংলা কুইজ — Premium Dark Upgrade
====================================

ফাইল:
- index.html: সম্পূর্ণ গেম
- manifest.json: PWA ইনস্টল সেটিংস
- sw.js: অফলাইন ক্যাশ
- icon-192.png / icon-512.png: অ্যাপ আইকন

সুবিধা:
- ৬টি কুইজ ক্যাটাগরি
- প্রতি প্রশ্নে টাইমার (সেটিংস থেকে ১০/১৫/২০/৩০ সেকেন্ড)
- দৈনিক চ্যালেঞ্জ
- High Score ও খেলার সংখ্যা এই ডিভাইসে সংরক্ষণ
- সাউন্ড ও ব্যাখ্যা চালু/বন্ধ
- PWA / Home Screen install এবং অফলাইন ক্যাশ

Android থেকে আপডেট করার নিরাপদ পদ্ধতি:
1. আপনার বর্তমান GitHub repository খুলুন।
2. পুরোনো index.html-এর একটি কপি আগে ডাউনলোড/সংরক্ষণ করুন।
3. Add file → Upload files নির্বাচন করুন।
4. এই প্যাকেজের index.html, manifest.json, sw.js, icon-192.png, icon-512.png আপলোড করুন।
5. Commit changes দিন।
6. Settings → Pages-এ আগের মতো main branch এবং /(root) আছে কি না নিশ্চিত করুন।
7. 2–5 মিনিট অপেক্ষা করে আপনার আগের লাইভ URL খুলুন। Chrome-এ পেজ রিফ্রেশ করুন।

গুরুত্বপূর্ণ:
- সব ফাইল একই repository-এর root-এ রাখুন; কোনো নতুন folder-এর ভিতরে নয়।
- README ফাইল আপলোড করা ঐচ্ছিক।
- GitHub Pages HTTPS-এ PWA চলে। প্রথমবার অনলাইন থাকা অবস্থায় সাইট খুলুন; এরপর ক্যাশ হওয়া ফাইল অফলাইনে খোলা যেতে পারে।
- High Score ও সেটিংস একই ব্রাউজার/ডিভাইসে localStorage-এ থাকে। অন্য ফোনে নিজে থেকে সিঙ্ক হবে না।
- প্রশ্নগুলো উদাহরণভিত্তিক। তথ্যভিত্তিক কুইজ প্রকাশের আগে প্রশ্ন ও উত্তর যাচাই করুন।
- Service worker আপডেট হতে কিছু সময় লাগতে পারে। নতুন সংস্করণ না এলে Chrome-এ পেজ রিফ্রেশ করুন, পরে আবার খুলুন।
- এটি কোনো অফিসিয়াল বাংলাদেশ সরকারি কুইজ অ্যাপ নয়।
